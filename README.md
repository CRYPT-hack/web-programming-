# Web Programming Class Content

## Course Overview
This class introduces the core technologies used to build modern websites and web applications.

## Learning Outcomes
By the end of the class, students should be able to:
- Explain how the web works (clients, servers, HTTP, and DNS)
- Build structured pages with HTML
- Style responsive layouts with CSS
- Add interactivity with JavaScript
- Create simple backend endpoints and connect frontend to backend
- Use Git and GitHub for version control and collaboration

## Core Topics
1. Internet and Web Fundamentals
2. HTML5 Structure and Semantics
3. CSS3 Styling, Layout, and Responsive Design
4. JavaScript Basics and DOM Manipulation
5. Forms, Validation, and Accessibility
6. REST APIs and JSON
7. Intro to Backend Development
8. Deployment Basics

## Suggested Practice
- Build a personal portfolio page
- Create a responsive landing page
- Implement a small CRUD web app
- Deploy a final project to a hosting platform
